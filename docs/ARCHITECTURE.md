# Архитектура

Bag Price Analyzer построен как последовательный pipeline с опциональными стадиями. Внешние интеграции изолированы в `services/`, особенности маркетплейсов — в `scrapers/`, а HTTP orchestration находится в `api/`.

## Поток обработки

1. `POST /analyze` принимает изображение и необязательный ценовой контекст.
2. Изображение валидируется и сохраняется во временную директорию.
3. `services/serpapi.py` отправляет изображение в Google Lens через SerpAPI.
4. Результаты нормализуются, дедуплицируются и ограничиваются поддерживаемыми доменами.
5. AI-gate определяет целевой бренд/модель и отбирает семантически близких кандидатов.
6. При включённом visual-режиме `services/clip.py` проверяет кандидатов по изображению.
7. `scrapers/dispatcher.py` направляет URL в доменные парсеры.
8. Цены, валюты, наличие и состояние товара приводятся к единому формату.
9. Pipeline удаляет выбросы и рассчитывает общую медиану, а также медианы доступных и проданных позиций.
10. API возвращает JSON. При включённой очереди Redis/RQ отдельно формируется HTML-отчёт.

## Границы компонентов

| Компонент | Ответственность |
|---|---|
| `api/` | HTTP-контракт, жизненный цикл запроса, сбор итогового ответа |
| `services/` | Внешние API, AI/ML, валюты, кэширование, очередь отчётов |
| `scrapers/` | Извлечение данных с конкретных доменов и общий fallback |
| `utils/` | Нормализация цен, изображения, HTTP transport, proxy и отчёты |
| `config.py` | Безопасное чтение `.env` и `.env.defaults` |

## Отказоустойчивость

- сетевые операции используют раздельные connect/read timeouts;
- доменные ошибки изолируются и не обрывают весь набор кандидатов;
- предусмотрены быстрый проход, selective refine, recovery и backfill;
- optional-интеграции пропускаются, если их credentials отсутствуют;
- Redis/RQ отделяет тяжёлую генерацию отчёта от основного HTTP-ответа;
- логи маскируют токены и proxy credentials.

## Данные и безопасность

Секреты поступают только через environment variables. Пользовательские изображения, результаты, кэш и логи являются runtime-данными и исключены из Git. Публичная версия не содержит production deployment, private proxy pools и исторические результаты анализа.
